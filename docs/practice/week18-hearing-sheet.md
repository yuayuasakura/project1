# 現状の課題
＜業務フロー＞
1. お店やオンラインでグッズを見つける
2. 持っているかどうかを記憶、スマホのメモ、写真フォルダで確認
3. 買うかどうかを決める
4. 家に帰って保管する
＜課題点＞
・一つだけ欲しいグッズを持っているのを忘れて二重に買ってしまう
・たくさん集めているグッズが今いくつあるのかわからない
・お店でメモや写真を探すのに時間がかかる
＜解決したいこと＞
・気になった時にすぐ持っているかどうかを確認したい
・集めているグッズの数を記録したい

# 目指す姿
＜システム導入後の理想＞
・スマホから検索すると持っているか、いくつ持っているかがすぐわかる
・一つでいいグッズは持っています、と表示され買わなくていいとわかる
・集めているグッズの数をメンバーごとに確認できる
＜期待する効果＞
・二重買いがなくなり、無駄な出費が減る
・お店で確認する時間が短くなる
・自分のコレクションを把握できる
＜成功の基準＞
・二重買いが0回になる
・グッズを検索してから結果が出るまで2秒以内
・ヒアリング相手~名中~名が使いやすいと答える
